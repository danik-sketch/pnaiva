# Notebook SPA Client

Современный React-приложение для управления заметками, проектами и задачами.

## Функциональность

### ✨ Основные возможности
- 👥 **Управление пользователями** (Create, Read, Update, Delete)
- �� **Управление проектами** с связью к пользователям (OneToMany)
- ✅ **Управление задачами** с поддержкой:
  - Связей с категориями (ManyToMany)
  - Напоминаниями (OneToMany)
  - Датами выполнения
- 🏷️ **Управление категориями** для задач
- 🔍 **Фильтрация и поиск** по проектам и категориям
- 📊 **Dashboard** со статистикой

## Структура связей

```
User (1) ──────── (Many) Project
                      │
                      └── (1) ──────── (Many) Task
                                          │
                                          ├── (1) ──────── (Many) Reminder
                                          │
                                          └── (Many) ──────── (Many) Category
```

## Технологии

- **React** 18.x - UI фреймворк
- **React Router** - навигация
- **Axios** - HTTP клиент
- **Vite** - сборщик
- **CSS3** - стилизация

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173`
